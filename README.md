# CycleNet（サイクルネット）静的サイト

このフォルダは **静的サイト**（HTML/CSS/JSのみ）です。サクラサーバへは、ファイルをアップロードするだけで公開できます。

## 含まれるファイル

- `index.html`
- `styles.css`
- `script.js`

## サクラサーバへアップロード手順（例）

1. サクラサーバのファイルマネージャー or FTP で接続
2. 公開先フォルダ（一般的に `www` / `public_html` など）へ移動
3. `index.html` / `styles.css` / `script.js` を同じ階層にアップロード
4. ブラウザでドメインにアクセスして表示確認

## 注意

- Google Fonts を利用しているため、閲覧時に外部通信が発生します（`fonts.googleapis.com` / `fonts.gstatic.com`）。
- 文字・連絡先（メール/電話）は `index.html` 内の値を実運用に合わせて差し替えてください。
